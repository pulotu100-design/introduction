Goals

My Goals For This Class

For this class, my main goal is to become more confident in building complete websites from start to finish. I would like to improve my ability to write clean, organized HTML and CSS, and to practice creating layouts that look good on both laptops and mobile devices. Another goal I have is to get more comfortable working on larger projects and organizing my files so that my websites are easy to maintain and update. I also hope to gain experience that will prepare me for working on group projects in the future.

Topics I Want to Review

From ITD 110, some of the areas I found confusing were using CSS Flexbox and Grid to create page layouts, and making websites responsive on different screen sizes. I would like more practice with those topics to feel comfortable applying them on my own. But I also found accessibility a little confusing, especially making sure that my pages can be used by screen readers or people with different needs. I want to better understand how to write code that meets accessibility standards.

What New Things I'd Like to Learn

I would like to start learning some JavaScript so I can add interactivity to my websites, such as dropdown menus, image sliders, and form validation. I'm also interested in learning more about accessibility and how to design websites that are usable for everyone. Finally, I want to learn how to publish and maintain websites so they can be viewed by the public. I would also like to explore CSS animations and transitions so I can create more engaging user experiences. Learning how to optimize a website for speed and performance is another area I think will be valuable for real-world projects.

What's Important to Cover in This Course

I think it is important that we cover best practices for writing clean, maintainable code and how to organize project files properly. Because I feel it would be helpful to work on projects that simulate real-world client work, so that we can practice not only coding but also problem-solving and design thinking. I think another important skill to cover is debugging and problem-solving when code doesn't work as expected. Learning how to use developer tools in the browser to find and fix errors is just as important as writing the code itself.
