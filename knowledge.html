Knowledge

My Knowledge

When I took ITD 110, Web Design 1, I was able to learn more of HTML and CSS from previous courses and foundations of how they are both used to build websites. I gained an understanding of page structure, semantic tags, linking pages together, and applying consistent styles with an external stylesheet. I also learned how to validate my code and check for errors, which taught me the importance of clean, accessible markup. But one challenge was experimenting with Javascripts because it took some time for me to figure out how to make my website work functionally, but over time, I was able to improve by practicing more. Overall, this course gave me some confidence and some skills to move forward in web development and prepared me for learning more advanced topics in this class.

My Strengths:

  • Understanding HTML5 structure and tags (headings, paragraphs, lists, images, links).
  • Using external CSS to apply consistent styles across a site.
  • Paying attention to detail, including indentation and file organization.
  • Experimenting with color themes and layouts to improve creativity.
  • Sketching out and designing layouts of the website before coding in.
  • Quickly adapting to new coding techniques and tutorials.

Areas I Need To Improve:

  • Remembering all the different CSS properties.
  • Improve JavaScript skills to program websites smoothly.
  • Becoming more confident in my design choices instead of second-guessing.
  • Making websites more responsive and mobile-friendly.
  • Experiment with more tools that can be useful to create websites.
